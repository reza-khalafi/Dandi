## 📖 معرفی پروژه (Overview)

**دَندی (Dandi)** یک سامانه و مجله مدرن وب بر پایه **جنگو (نسخه ۶.۱)** و **Tailwind CSS** است که بر مبنای اصول مهندسی نرم‌افزار تمیز، معماری چندلایه‌ای (`View - Service - Repository`) و تایپوگرافی اصیل فارسی (فونت یکپارچه وزیرمتن) توسعه یافته است.

نام و نشان دَندی برگرفته از گل قاصدک (Dandelion) و دانه‌های شناور در باد است؛ استعاره‌ای از بذر اندیشه‌ها، ایده‌ها و روایت‌هایی که در گستره ذهن به پرواز درمی‌آیند و بر خاک حاصلخیز تفکر می‌نشینند.

این پلتفرم تنها محدود به یک حوزه نیست، بلکه قلمروهای چندرشته‌ای را در بر می‌گیرد:
1. **اندیشه، فلسفه و سبک زندگی** (خرد زیسته، آرامش درونی، هنر آهستگی و خودشناسی)
2. **علم، فناوری و جهان نو** (کیهان‌شناسی، هوش مصنوعی، تفکر سیستمی و افق‌های محاسباتی)
3. **هنر، ادبیات و خلاقیت** (زیبایی‌شناسی، تایپوگرافی، روایت‌گری، دیزاین معاصر و تجربه ادراک حسی)

## ✨ ویژگی‌های برجسته (Key Features)

### ۱. معماری لایه‌ای تمیز (Layered Architecture)
- **لایه View (نما)**: کنترلرهای نازک و منسجم جهت دریافت درخواست‌های HTTP، مدیریت فرم‌ها و بازگرداندن پاسخ‌های HTML یا JSON (هر نما در فایل مجزا).
- **لایه Service (سرویس‌ها)**: تفکیک دقیق منطق بیزینس، اعتبارسنجی‌ها، شمارش بازدیدها و هماهنگی میان منابع.
- **لایه Repository (مخازن داده)**: انتزاع کامل کوئری‌های دیتابیس (ORM)، بهینه‌سازی دسترسی با `select_related` و `prefetch_related`.
- **ریزمدل‌ها و Enumها**: استفاده از `TextChoices` برای وضعیت‌های مقالات و دیدگاه‌ها و تفکیک موجودیت‌های خرد نظیر `Category`، `Tag` و `Comment`.

### ۲. رابط کاربری، موشن دیزاین و تایپوگرافی
- **فونت یکپارچه وزیرمتن (Vazirmatn)**: اعمال استاندارد در سراسر وب‌سایت، عناوین، ورودی‌ها و فرم‌ها با فاصله خطوط (line-height) گشاده و خوانا.
- **هیرو سکشن تمام‌عرض (Full-Row Panoramic Hero)**: دارای عکس عکاسی باکیفیت در یک ردیف کامل، همراه با پارالکس ملایم (واکنش به ماوس و اسکرول) و المان‌های شناور قاصدک.
- **کارت‌های تعاملی قلمروها (Topic Discovery Board)**: نمایش موضوعات به شکل کارت‌های تعاملی ۴ گانه با نمایش وضعیت فعال، آیکون‌های گرادیان و شمارشگر مقالات.
- **۴ تم چندگانه (Multi-Theme Support)**:
  - ☀️ **سفید و مینیمال (Light Minimal)**: تم روز با رنگ‌های سفید، خاکستری، نارنجی و بنفش لایت.
  - 🌌 **شب لاجوردی (Midnight Cobalt)**: تم تیره کلاسیک با پالت آبی تیره و نارنجی تابان.
  - 🔮 **شب مخملی (Deep Velvet)**: تم تیره لوکس با بنفش سلطنتی و زرد خورشیدی.
  - 🌆 **غروب سایبر (Cyber Dusk)**: تم گرافیت مدرن با نارنجی نئونی و بنفش متالیک.
  - *تغییر آنی بدون رفرش و ذخیره‌سازی در `localStorage`.*

### ۳. لود تدریجی مقالات (Infinite Scroll) و جستجوی زنده
- لود صفحات به صورت تکه‌تکه با اسکرول (استفاده از IntersectionObserver در جاوااسکریپت خالص).
- سرچ آنی و هوشمند (Live Debounced Search) در عنوان، خلاصه، متن و تگ‌ها بدون بارگذاری مجدد صفحه.

### ۴. سامانه ثبت‌نام، ورود و دیدگاه‌ها
- فرم ثبت‌نام و ورود امن با احراز هویت جنگو و استایل‌های یکپارچه.
- استفاده از همان نشان و لوگوی ثابت و زیبای دَندی در صفحات ورود و ثبت‌نام.
- امکان ارسال دیدگاه به صورت AJAX با بروزرسانی در لحظه، مختص کاربران عضو.
- کارت راهنمای هوشمند ورود برای کاربران مهمان.

### ۵. ۵۰ مقاله جامع و رسانه‌های واقعی
- پایگاه‌داده مجهز به ۵۰ جستار تحلیلی با طول **بیش از ۳۰۰۰ کلمه** برای هر مقاله (مجموعاً بیش از ۴۰۰,۰۰۰ کلمه محتوا).
- بهره‌گیری از تصاویر عکاسی واقعی و استاندارد در پوشه `media/articles/demo/`.

## 🚀 خلاصه راه‌اندازی سریع (Quick Start)

### ۱. دریافت مخزن و ساخت محیط مجازی
```bash
git clone https://github.com/reza-khalafi/Dandi.git
cd Dandi

python3 -m venv .venv
source .venv/bin/activate  # در ویندوز: .\.venv\Scripts\Activate.ps1
```

### ۲. نصب بسته‌ها و کپی متغیرهای محیطی
```bash
pip install --upgrade pip
pip install -r requirements.txt

cp .env.example .env       # در ویندوز CMD: copy .env.example .env
```

### ۳. ایجاد دیتابیس لوکال و داده‌های اولیه
```bash
python manage.py migrate
python manage.py seed_data
```
*اطلاعات حساب مدیر پیش‌فرض ساخته‌شده:*
- نام کاربری: `admin` | رمز عبور: `admin123456`

### ۴. اجرای سرور توسعه
```bash
python manage.py runserver
```
سایت در آدرس [http://127.0.0.1:8000](http://127.0.0.1:8000) و دستیار هوشمند در [http://127.0.0.1:8000/assistant/](http://127.0.0.1:8000/assistant/) در دسترس است.
