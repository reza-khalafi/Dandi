# راهنمای اجرای لوکال پروژه دَندی روی مک‌اواس (macOS)

این سند راهنمای گام‌به‌گام راه‌اندازی و اجرای محلی پروژه **دَندی (Dandi)** بر روی سیستم‌عامل **macOS** (پشتیبانی کامل از پردازنده‌های **Apple Silicon M1/M2/M3/M4** و پردازنده‌های **Intel**) به همراه دیتابیس لوکال SQLite می‌باشد.

---

## 📋 ۱. پیش‌نیازهای سیستمی مک‌اواس

برای اجرای روان پروژه در مک، داشتن ابزارهای زیر توصیه می‌شود:

1. **نصب ابزارهای خط فرمان Xcode (Command Line Tools):**
   در برنامه **Terminal** دستور زیر را اجرا فرمایید:
   ```bash
   xcode-select --install
   ```
   *(در صورت باز شدن پنجره اعلان، گزینه Install را تایید کنید).*

2. **مدیریت بسته‌ها با Homebrew (در صورت عدم نصب):**
   اگر هوم‌برو ندارید، با دستور زیر آن را نصب کنید:
   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

3. **نصب پایتون ۳ و گیت از طریق Homebrew:**
   ```bash
   brew install python git
   ```
   با اجرای `python3 --version` اطمینان حاصل کنید که نسخه پایتون **3.11** یا جدیدتر است.

## 🚀 ۲. مراحل گام‌به‌گام راه‌اندازی محلی

### گام اول: دریافت کد پروژه (Git Clone)
ترمینال را باز کرده و مخزن را در پوشه دلخواه خود (مثلاً `~/Sites` یا `~/Projects`) کلون کنید:
```bash
cd ~/Sites
git clone git@github.com:reza-khalafi/Dandi.git
cd Dandi
```
*(یا با آدرس HTTPS: `git clone https://github.com/reza-khalafi/Dandi.git`)*

---

### گام دوم: ساخت محیط ایزوله مجازی پایتون (Virtualenv)
یک محیط مجازی تمیز درون پوشه ریشه پروژه بسازید و آن را فعال کنید:
```bash
python3 -m venv .venv
source .venv/bin/activate
```
*(پس از فعال‌سازی، عبارت `(.venv)` در سمت چپ پرامپت خط فرمان ظاهر می‌شود.)*

---

### گام سوم: نصب بسته‌ها و کتابخانه‌های مورد نیاز
ابزار مدیریت بسته pip را به‌روزرسانی کرده و نیازمندی‌ها را نصب نمایید:
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

---

### گام چهارم: پیکربندی متغیرهای محیطی (.env)
یک فایل تنظیمات محلی از روی نمونه پیش‌فرض ایجاد کنید:
```bash
cp .env.example .env
```

فایل `.env` را با ادیتور دلخواه (مانند VS Code، Cursor، Sublime یا nano) باز کنید:
```bash
open -e .env
```
تنظیمات زیر را در آن قرار دهید یا ویرایش کنید:
```env
# تنظیمات امنیتی پایه جنگو
DJANGO_SECRET_KEY="یک_کلید_محرمانه_تصادفی"
DJANGO_DEBUG=True
DJANGO_ALLOWED_HOSTS=*

# دسترسی به دستیار هوش مصنوعی Groq
GROQ_API_KEY=gsk_your_groq_api_key_here
GROQ_MODEL=qwen/qwen3.8-27b
PYDANTIC_AI_NO_BANNER=1
```

> 💡 **تولید خودکار کلید امن جنگو در مک:**
> می‌توانید دستور تک‌خطی زیر را در ترمینال اجرا کنید و خروجی را در متغیر `DJANGO_SECRET_KEY` کپی کنید:
> ```bash
> python3 -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
> ```

---

### گام پنجم: ایجاد پایگاه‌داده محلی SQLite و اجرای مایگریشن‌ها
جنگو بدون نیاز به نصب هیچ دیتابیس جداگانه‌ای، جداول را در یک فایل محلی سریع به نام `db.sqlite3` ایجاد می‌کند:
```bash
python manage.py migrate
```

---

### گام ششم: درج مقالات نمونه، دسته‌بندی‌ها و تصاویر (Seed Data)
برای اینکه مجله با محتوای جذاب فارسی، دسته‌بندی‌های تخصصی و مقالات پر شود:
```bash
python manage.py seed_data
```
این دستور تصاویر پیش‌فرض را همگام‌سازی کرده و دیتابیس را با مقالات و نظرات آماده می‌کند.

---

### گام هفتم: اجرای تست‌های سامانه (پیشنهادی)
برای بررسی عملکرد صحیح تمامی بخش‌ها و ۱۴ متدولوژی تست:
```bash
python manage.py test tests
```
*(تمامی تست‌ها باید با خروجی سبز و وضعیت `OK` به پایان برسند).*

---

### گام هشتم: اجرای وب‌سرور دَندی روی مک
سرور توسعه لوکال را اجرا کنید:
```bash
python manage.py runserver 127.0.0.1:8000
```

حال با مرورگر (سافاری، کروم یا فایرفاکس) آدرس زیر را باز کنید:
👉 **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)**

```bash

```

## 🛠️ ۴. نکات و رفع مشکلات رایج در مک‌اواس (Troubleshooting)

1. **تداخل پورت ۸۰۰۰ با سرویس‌های دیگر:**
   - اگر خطای `That port is already in use` را مشاهده کردید:
     ```bash
     lsof -ti:8000 | xargs kill -9
     ```
     یا می‌توانید سرور را روی پورتی دیگر مانند ۸۰۸۰ اجرا کنید:
     ```bash
     python manage.py runserver 127.0.0.1:8080
     ```

2. **خطای گواهی امنیتی SSL در پایتون مک:**
   - اگر هنگام دانلود پکیج‌ها یا اتصال هوش مصنوعی با خطای گواهی SSL مواجه شدید:
     ```bash
     /Applications/Python\ 3.*/Install\ Certificates.command
     ```

3. **خروج از محیط مجازی پس از پایان کار:**
   - هر زمان کارتان با پروژه به پایان رسید، با دستور زیر محیط مجازی را ببندید:
     ```bash
     deactivate
     ```
